# Material Symbols

Filled (`FILL@1`) Material Symbols Outlined icons (weight 400, 24px) for selected navigation
destinations, bundled locally because `@expo/material-symbols` ships only the unfilled style.
Generate more with `npx add-material-symbols --fill -o assets/symbols <name>` and add a
`<name>_fill.xml.d.ts` beside each, then name the glyph in `src/ui/glyphs.ts`.

`filter_cancel` (outlined), which `@expo/material-symbols` lacks, comes from vaka as its clear
filters icon.
